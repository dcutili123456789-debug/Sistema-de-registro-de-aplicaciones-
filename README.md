# Sistema de Registro de Calificaciones

## Descripción

Este proyecto consiste en un sistema para registrar y gestionar las calificaciones de estudiantes. Permite ingresar datos, procesarlos y mostrar los resultados de manera organizada.

## Funcionalidades

- Registrar datos de los estudiantes.
- Ingresar calificaciones.
- Validar los datos introducidos.
- Calcular y mostrar los resultados.
- Mostrar mensajes de error cuando los datos son incorrectos.

## Validaciones

El programa valida que los datos ingresados sean correctos y que las calificaciones se encuentren dentro del rango permitido.

## Manejo de errores

Se consideran errores como el ingreso de datos inválidos, valores fuera del rango permitido y entradas que no corresponden al tipo de dato solicitado.

## Pruebas realizadas

Se realizaron pruebas con:

- Datos válidos.
- Datos inválidos.
- Calificaciones fuera del rango permitido.
- Entradas incorrectas.
- Diferentes estudiantes y calificaciones.

Las pruebas permitieron detectar y corregir errores para mejorar el funcionamiento del programa.
